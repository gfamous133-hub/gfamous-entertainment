# GFAMOUS Entertainment

A responsive, mobile-first entertainment discovery prototype for movies, TV series and music.

## Included
- Dark and gold responsive interface
- Home, Movies, TV Series, Music and My List sections
- Search and category filters
- English / Swahili interface toggle
- Locally saved favourites (browser localStorage)
- Demonstration catalogue entries clearly labelled as placeholders

## Run locally
Open `index.html` in a modern browser.

## Deploy with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the Pages deployment to finish.

## Important limitations
This is a front-end prototype. It does not provide user accounts, a server-side database, a secure admin dashboard, licensed media, or video/audio streaming. Sample titles are placeholders. Add real catalogue entries and playback only when GFAMOUS has the necessary distribution rights and authorized media providers. Do not upload copyrighted films or music without permission.
